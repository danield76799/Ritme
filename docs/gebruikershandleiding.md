# Ritme Gebruikershandleiding

## Welkom bij Ritme

Ritme is jouw persoonlijke SRT (Social Rhythm Therapy) tracker. De app helpt je om je dagelijkse ritme te monitoren, stemming te volgen en je sociale activiteiten te registreren.

---

## 📱 Hoofdscherm (Dashboard)

Het dashboard geeft een overzicht van je huidige status:

### Overzichtskaarten
- **Slaapscore** - Gemiddelde slaapduur in uren
- **SRT Score** - Percentage activiteiten binnen je richttijd (±45 minuten)
- **Activiteiten deze week** - Totaal aantal geregistreerde activiteiten

### Stemming Trend
Een lijndiagram toont je stemming over de laatste 7 dagen:
- **Y-as**: Stemmingsschaal (-5 tot +5)
  - -5 = Uiterst depressief
  - 0 = Neutraal
  - +5 = Uiterst manisch
- **X-as**: Datums

### Snelle Acties
- **+ Belangrijke Gebeurtenis** - Voeg een life event toe

Vanuit het hoofdmenu kun je naar verschillende schermen:

## 📊 SRT Score Uitleg

De SRT (Social Rhythm Therapy) score geeft aan hoe stabiel je dagelijkse ritme is:

### P-Score Schaal (per activiteit)
| Punten | Tolerantie | Betekenis |
|--------|-----------|-----------|
| 5 | ±15 min | Perfect |
| 4 | ±30 min | Goed |
| 3 | ±45 min | Acceptabel (cutoff) |
| 2 | ±60 min | Matig |
| 1 | >60 min | Slecht |
| 0 | Geen activiteit | Gemist |

### SRT Score Berekening
```
SRT Score = (Gemiddelde P-Score / 5) × 100%
```

**Interpretatie:**
- **80-100%** - Uitstekend stabiel ritme ✅
- **60-79%** - Goed, kleine variaties
- **40-59%** - Matig, aandacht nodig
- **20-39%** - Instabiel, interventie aanbevolen
- **0-19%** - Zeer instabiel, hulp zoeken

## 🎭 Stemmingsschaal

Ritme gebruikt de officiële SRM (Social Rhythm Metric) stemmingsschaal:

### Schaal: -5 tot +5

| Waarde | Label | Kleur |
|--------|-------|-------|
| -5 | Uiterst depressief | Donkergrijs |
| -4 | Ernstig depressief | Grijs |
| -3 | Matig depressief | Blauwgrijs |
| -2 | Licht depressief | Lichtblauw |
| -1 | Licht depressief | Zeer lichtblauw |
| 0 | Neutraal | Groen |
| +1 | Licht manisch | Geel |
| +2 | Licht manisch | Oranje |
| +3 | Matig manisch | Donkeroranje |
| +4 | Ernstig manisch | Rood |
| +5 | Uiterst manisch | Donkerrood |

### Stemming Invoeren
1. Open het dagelijkse logboek
2. Selecteer de datum
3. Gebruik de slider om je stemming aan te geven
4. Sla op

## 📈 Gegevens Exporteren

Je kunt al je gegevens exporteren als JSON:
1. Ga naar Instellingen
2. Selecteer "Exporteer Gegevens"
3. Het bestand wordt opgeslagen in je Downloads

**Export bevat:**
- Dagelijkse logs (slaap, stemming, activiteiten)
- Medicatiegegevens
- Gewichtslogboek
- Afspraken
- Life events

## 🔒 Privacy & Beveiliging

- Alle gegevens worden lokaal opgeslagen
- Optionele PIN-bescherming beschikbaar
- Geen data wordt naar externe servers gestuurd

---

## 💡 Tips voor Effectief Gebruik

1. **Regelmatig invullen** - Doe het dagelijks op hetzelfde moment
2. **Wees eerlijk** - Accurate data geeft betere inzichten
3. **Gebruik de SRT score** - Als deze daalt, is dat een signaal
4. **Life events noteren** - Belangrijke gebeurtenissen beïnvloeden je ritme
5. **Medicatie consistent** - Neem je medicatie op vaste tijden
